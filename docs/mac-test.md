# LaunchOne macOS lab 测试包

适用 macOS 12+，支持 Apple Silicon 和 Intel。版本 0.1.1，替换此前未接入的 0.1.0 包。

## 使用

1. 打开 DMG，将 LaunchOne 拖入“应用程序”，然后打开。
2. 点击“登录 IDONE”，在浏览器完成登录并确认设备。
3. 在 Codex 或 Claude Code 卡片点击“启用 TokenOne”；首次使用按浏览器提示完成授权。未安装的工具先点击安装。

lab 地址、默认模型和 public client 已内置，不需要填写 Base URL、Key 或服务配置。个人 Key 由本人登录后获取，服务端应用凭证不进入安装包。工具配置写入前保存相关字段的旧值，失败时回滚，支持恢复原配置。

Mac 需要能访问 lab 内网、解析 `*.lab.home.arpa`，并已信任 lab 根证书。应用沿用系统信任，不跳过 HTTPS 验证。

测试包使用本地签名，未做 Apple 公证。若系统阻止打开，先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。不要关闭系统整体安全检查。
