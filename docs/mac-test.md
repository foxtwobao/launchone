# LaunchOne macOS 测试包

适用 macOS 12+，同时支持 Apple Silicon 和 Intel。版本 0.1.0。

## 安装

打开 DMG，将 LaunchOne 拖入“应用程序”，然后打开。也可以解压 `.app.zip` 后将应用移入“应用程序”。两种格式内容相同，任选其一。

测试包使用本地签名，未做 Apple 公证。如果系统阻止打开，先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。不要关闭系统整体安全检查。

## 本次测试范围

- 窗口、布局、菜单和应用状态刷新。
- 发现已经安装的 Codex CLI、Claude Code，以及未安装时的提示。
- 官方渠道安装和官方登录入口；切换配置前应用会保留相关字段备份。

当前尚未登记独立 IDONE 客户端和 Reseller 应用，测试构建未注入这些参数时，IDONE 登录和 TokenOne 启用按钮会保持不可用。这次不能验收真实 TokenOne 登录、取 Key 或模型调用。

点击安装、切换和恢复按钮会实际操作本机工具及配置，请在专用测试用户下验收。仅打开应用和刷新状态不会主动替换 CLI 配置。
