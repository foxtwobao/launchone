# LaunchOne macOS 0.2.3 桌面版内测

支持 Apple Silicon / Intel 的 LaunchOne 通用包；目标应用还需支持当前芯片和系统版本。替换 0.1.1 后，首页改为桌面应用检测，不再以 PATH 中的 CLI 判断是否安装。

0.2.3 测试包包含直接恢复原接入配置和底部版本号显示；本测试包未做 Apple 公证。

## 使用

1. 打开 DMG，将 LaunchOne 拖入“应用程序”。测试包未做 Apple 公证；若系统阻止打开，到“系统设置 → 隐私与安全性”选择“仍要打开”，不要关闭全局安全检查。
2. 已安装的 ChatGPT / Codex、Claude 直接点击“打开”，无需登录 IDONE；应用已在运行时会提示确认重新打开，选择“稍后”保持运行。未安装时点击“安装”，macOS 使用官方 DMG、检查签名与芯片，将应用安装到当前用户的 Applications。
3. 首次登录 IDONE 后，自动为已安装且检测支持接入的应用准备 TokenOne；不会批量安装其他应用。个人 Key、地址和默认模型无需填写。
4. 在卡片直接切换“TokenOne / 官方订阅”。主动切回订阅后会记住选择，重启或再次登录不强制改回。官方登录和订阅资格由原客户端确认。
5. Codex 切换保留已有官方账号身份，继续使用同一套项目与桌面状态；模型请求使用 TokenOne Key。不会复制或覆盖项目数据库、SSH 配置、原登录凭据或问卷记录。尚未官方登录的用户也可直接使用 TokenOne。
6. 切换后会提示重新打开，先保存工作，再确认“重新打开”。选择“稍后”不会退出应用，下次点击“打开”可再次确认。正常退出失败时会提示手动处理，不强制结束任务。

卡片右上角“高级”菜单提供“恢复原配置”，点击后直接按首次备份恢复 LaunchOne 管理的接入字段，覆盖这些字段的后续修改，保留项目、SSH 和其他无关设置。恢复后也不自动改回 TokenOne。macOS 使用系统可信证书；Mac 需能访问 lab 内网、解析 `*.lab.home.arpa` 并信任 lab 根证书。

## 验证范围

已验证隔离配置中的订阅切换、恢复、多文件失败回滚、中断恢复、原有配置保护和界面交互；测试不写真实用户目录或钥匙串。此前 lab 的真实设备登录、刷新、Key 获取、两个 CLI 的模型和工具调用继续有效。

本次新增隔离验证：有账号时保留身份、无账号时不强制官方登录；多次切换与恢复后，本地/SSH 项目配置、凭据和桌面状态文件保持不变。Codex 0.167.0 连接本地模拟服务，确认原官方 Key 留在本地，实际请求使用明确配置的 TokenOne Key。

当前桌面适配仍需真机验收（包括项目列表显示与不重复问卷）：实际应用版本是否读取配置、Chat / Code / Cowork 各入口、登录状态、流式输出、工具调用及重启生效。配置与 HTTP 连接测试成功不等于上述全部桌面功能已经通过。旧 ChatGPT 安装可直接打开，未检测到 Codex 网关引擎时不自动配置 TokenOne；TokenOne 的 Codex 配置不宣称改写普通 ChatGPT 聊天的模型路由。

请反馈系统版本、芯片、目标应用版本和错误步骤，不要发送 Key、密码、Cookie 或原始凭据文件。下载完整性用 `SHA256SUMS.txt` 检查。
